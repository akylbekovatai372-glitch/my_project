# Ответы для самопроверки

1. Папка `venv` содержит локальную копию интерпретатора и установленные пакеты. Она большая, зависит от операционной системы и версии Python, а её содержимое можно восстановить. Поэтому виртуальное окружение не коммитят.

2. После клонирования репозитория другой разработчик создаёт своё окружение командой `python3 -m venv venv`, активирует его и устанавливает зависимости командой `python -m pip install -r requirements.txt`.

3. `requirements.txt` перечисляет зависимости проекта и их версии. Его коммитят, чтобы окружение можно было восстановить. `.gitignore` исключает локальные и генерируемые файлы, например `venv/`, `__pycache__/` и `*.pyc`; сам `requirements.txt` в исключения не добавляют.
